每日吉卜力 · 0.4.3

需要 macOS 14 或以上。当前随附的应用为 Apple Silicon 版本。

使用
1. 双击“每日吉卜力.app”后，菜单栏出现 photo.on.rectangle.angled 图片图标；没有独立窗口或 Dock 图标。
2. 点击图标打开系统原生菜单，在“影片”子菜单中选择作品，再点击“换一张”。
3. “恢复上次壁纸”可撤销最近一次换图；“退出”关闭工具。
4. 下载失败时，菜单会出现“查看错误…”。
5. 菜单按“操作”“壁纸信息”“设置”分组。“壁纸信息”显示当前壁纸的作品名称，点击即用默认浏览器打开该作品的吉卜力官方介绍页面。多显示器分别显示屏幕名称与对应作品；换图或恢复后同步更新。

按需下载
打开菜单、选择影片和修改设置都不会提前下载图片。手动或定时切换时才向吉卜力官网下载所需图片，全部下载并验证成功后再设置桌面。下载文件保存于 ~/Library/Application Support/DayGhibli/Wallpapers。

自动清理
只保留已记录各显示器当前和上一张壁纸，共用图片只留一份，暂未连接的显示器记录也会保留。应用启动、成功换图及恢复后自动清理；下载、设置或保存失败时跳过清理。只处理本工具缓存目录的图片，不处理外部文件、符号链接或子目录。

设置
“各显示器独立随机”：关闭时所有连接显示器用同一张图；开启后每块屏幕各下载一张不同的随机图。设置在下一次切换时生效。
“自动切换”：按所选频率切换；休眠错过会在唤醒后补换，下载失败15分钟后重试。成功手动换图或调整频率后重排下一次任务。首次默认关闭。
“切换频率”二级菜单：每小时、每6小时、每天、每周。小时模式从开启或上次成功切换计时；每天为当地09:00，每周为当地周一09:00。默认每天。修改频率不会立即下载。
“登录时启动”：使用macOS系统登录项，开启后在此用户后续登录时启动工具。需要系统批准时，菜单提供“在系统设置中允许…”入口。此开关读取系统状态，不在启动应用时自动注册登录项。
自动切换需要工具保持运行。多虚拟桌面的行为由 macOS 控制，当前版本不承诺同步所有 Space。

开发
需要 Xcode 或包含 macOS SDK 的 Swift 6 工具链。./build.sh 编译并打包当前架构的应用；可用 APP_OUTPUT 和 BUILD_DIR 指定路径。swift test 运行测试。无第三方依赖。

验证（2026-11-02）
35 项自动测试通过，覆盖按需下载、双屏分配、失败重试、频率日期边界、设置迁移、每屏两张保留、断开屏保护、失败跳过清理、文件清理范围，以及菜单作品页面的每屏关联、旧状态兼容、换图/恢复/重启同步和外部换图。登录启动通过替身服务验证。此前已用本机真实计时器验证共享/独立双屏切换及恢复原壁纸。

卸载
退出后删除应用即可。若需移除本地图片和设置，可自行删除 ~/Library/Application Support/DayGhibli 文件夹。
